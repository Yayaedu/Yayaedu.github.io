Noter

C# Grundlæggende

  • Klasser er skabeloner – objekter er instanser af klasser
  • MonoBehaviour er base-klassen for alle Unity scripts
  • SerializeField eksponerer private variable i Inspector
  • Awake() kører før Start() – brug Awake til initialisering
  • Update() kører hver frame, FixedUpdate() kører fast (fysik)
  • Coroutines bruger yield return – tillader tidsforsinkede handlinger
  • Events og Actions bruges til løs kobling mellem scripts
  • Singleton pattern: én instans tilgængelig globalt via static reference
  • async/await bruges til asynkrone operationer (Firebase, netværk)
  • enum definerer en navngivet mængde af konstanter

Unity Koncepter

  • GameObject er alle objekter i en Unity scene
  • Komponenter tilføjes GameObjects og definerer adfærd
  • Prefabs er genanvendelige GameObject-skabeloner
  • NavMesh bages på terræn – NavMeshAgent navigerer automatisk
  • Raycast sender en usynlig stråle og returnerer hvad den rammer
  • CharacterController giver FPS-bevægelse uden Rigidbody-fysik
  • Canvas bruges til UI – World Space vs Screen Space
  • TextMeshPro giver bedre tekstrendering end standard UI Text
  • AudioSource afspiller lyd – AudioClip er selve lydfilen
  • URP (Universal Render Pipeline) – opgraderede shaders kræves
  • ProBuilder bruges til at modellere 3D geometry direkte i Unity
  • Mathf.Pow(base, exponent) – bruges til eksponentiel sværhedsgrad

Flutter og Dart

  • Alt i Flutter er widgets – UI bygges som et widget-træ
  • StatelessWidget har intet state – StatefulWidget kan opdateres
  • setState() fortæller Flutter at UI skal genopbygges
  • BuildContext er en widgets adresse i widget-træet
  • Navigator.push/pop bruges til navigation mellem skærme
  • Future er et enkelt asynkront resultat – Stream er en kontinuerlig strøm
  • StreamBuilder genopbygger UI automatisk ved nye stream-data
  • GlobalKey bruges til at tilgå FormState udefra
  • mounted-check er obligatorisk efter await i StatefulWidget
  • Navigator.pop() skal kaldes synkront før enhver await-operation

Firebase

  • Firestore struktur: collections > documents > fields
  • Datoer gemmes som Timestamp – skal konverteres ved læsning
  • Offline persistence: data caches lokalt – kan skjule fejl
  • PERMISSION_DENIED vises ikke direkte hvis offline cache er aktiv
  • authStateChanges() er en stream der lytter på login-status
  • Sikkerhedsregler defineres i Firestore Console
  • google-services.json skal være i android/app mappen

Læringsmål

Valgfag: Flutter mobiludvikling – Global Gaming Booking App

Viden

Jeg har:

  • forståelse for, hvordan Flutter og Dart anvendes til udvikling af mobilapplikationer.
  • viden om opbygning af brugergrænseflader og navigation mellem forskellige sider i en app.
  • forståelse for, hvordan Firebase anvendes som backend og database til autentifikation og lagring af data.
  • kendskab til bookinglogik og håndtering af reservationer i databaser.
  • forståelse for principper inden for UX og responsivt design til mobilapps.

Færdigheder

Jeg kan:

  • udvikle en funktionel mobilapplikation i Flutter med login- og bookingsystem.
  • implementere funktioner til booking af gamingstationer og visning af ledige tider.
  • anvende Firebase til lagring og synkronisering af brugerdata.
  • analysere og fejlrette problemer i appens kode og databasestruktur.
  • designe en brugervenlig app med fokus på funktionalitet og brugeroplevelse.

Kompetencer

Jeg kan:

  • selvstændigt planlægge og udvikle en komplet bookingapp til en gaming café.
  • vurdere og optimere appens performance, sikkerhed og struktur.
  • reflektere over mine valg af teknologier og designløsninger i udviklingsprocessen.
  • videreudvikle appen med nye funktioner som betalingssystem eller adminpanel.
  • anvende min viden om Flutter og Firebase i andre typer softwareprojekter.
Valgfag: Spiludvikling i Unity – Zombie Wave Survival-spil

Viden

Jeg har:

  • forståelse for grundlæggende spiludvikling i Unity og programmering i C#.
  • viden om game loops, wave-systemer og enemy AI i survival-spil.
  • forståelse for collision detection, animationer og fysiksystemer i Unity.
  • kendskab til leveldesign og gameplay-mekanikker i FPS-spil.
  • forståelse for balancing og brugeroplevelse i spiludvikling.

  • implementere våben, pointsystem og rundeprogression.
  • anvende Unitys værktøjer til animation, lys, lyd og effekter.
  • analysere og optimere gameplay og performance gennem testning.

Kompetencer

Jeg kan:

  • selvstændigt udvikle og strukturere et større spilprojekt fra idé til færdigt produkt.
  • vurdere og forbedre gameplay og mekanikker for at skabe en bedre spilleroplevelse.
  • reflektere over mine designvalg og inspiration fra spil som BO2 Zombies.
  • videreudvikle spillet med nye funktioner som multiplayer eller avanceret AI.
  • anvende min viden om Unity til udvikling af andre spil og interaktive projekter.

Unity Zombie Survival Spil

NavMeshAgent – Manual
Officiel Unity dokumentation for NavMesh opsætning og AI navigation.
https://docs.unity3d.com/Manual/nav-CreateNavMeshAgent.html
Præcis og fyldestgørende. Dækkede alt fra NavMesh baking til agent-konfiguration. Essentiel for implementering af zombie-AI.
NavMeshAgent.SetDestination()
Script Reference til den metode der bruges til at sætte zombiernes bevægelsesmål.
https://docs.unity3d.com/ScriptReference/AI.NavMeshAgent.SetDestination.html
Kortfattet og direkte anvendelig. Klar beskrivelse af parametre og returværdier.
CharacterController – Manual
Dokumentation for CharacterController komponenten brugt til FPS spillerbevægelse.
https://docs.unity3d.com/Manual/class-CharacterController.html
God forklaring af forskellen mellem CharacterController og Rigidbody, hvilket hjalp med at træffe det rigtige valg til FPS bevægelse.
CharacterController.Move()
Script Reference til Move()-metoden der håndterer selve bevægelsen frame for frame.
https://docs.unity3d.com/ScriptReference/CharacterController.Move.html
Præcis dokumentation med nyttige noter om kollisionsdetektion og gravity-håndtering.
Physics.Raycast()
Script Reference til Raycast-metoden brugt i hitscan våbensystemet.
https://docs.unity3d.com/ScriptReference/Physics.Raycast.html
Essentiel kilde. Parametrene er godt forklaret og eksemplerne er direkte anvendelige i våbensystemet.
Camera.ViewportPointToRay()
Script Reference til at skyde Raycast fra skærmens midte frem for kameraets position.
https://docs.unity3d.com/ScriptReference/Camera.ViewportPointToRay.html
Kort men præcis. Nødvendig for korrekt FPS-sigtning fra crosshair frem for fra kameraets kant.
Coroutines – Manual
Officiel forklaring af Coroutines i Unity, brugt til reload-animation og spawn-forsinkelser.
https://docs.unity3d.com/Manual/Coroutines.html
Meget god introduktion til et koncept der ikke er intuitivt. Forklaringen af yield return new WaitForSeconds() var direkte anvendelig.
WaitForSeconds
Script Reference til WaitForSeconds brugt i coroutines til tidsbaserede handlinger.
https://docs.unity3d.com/ScriptReference/WaitForSeconds.html
Kort og præcis. God note om at WaitForSeconds er upåvirket af Time.timeScale.
URP – Introduction
Introduktion til Universal Render Pipeline brugt til at løse pink material-problemet.
https://docs.unity3d.com/Manual/urp-introduction.html
Nyttig oversigt over URP og opgradering af materialer. Hjalp med at forstå hvorfor materialer skal konverteres og hvordan.
ProBuilder – Manual
Dokumentation for ProBuilder brugt til at modellere spillets map direkte i Unity.
https://docs.unity3d.com/Packages/com.unity.probuilder@5.0/manual/index.html
Fyldestgørende dokumentation med gode illustrationer. Dækker alle de grundlæggende værktøjer der bruges til level-bygning.
TextMeshPro – Manual
Dokumentation for TextMeshPro brugt til HUD-tekst med health, points og ammo.
https://docs.unity3d.com/Manual/com.unity.textmeshpro.html
Klar dokumentation. TextMeshPro er det anbefalede alternativ til Unity UI Text og dokumentationen forklarer migreringen godt.
AudioSource.PlayOneShot()
Script Reference til PlayOneShot() brugt til våbenlyde og effekter.
https://docs.unity3d.com/ScriptReference/AudioSource.PlayOneShot.html
Præcis forklaring af forskellen på PlayOneShot og Play – vigtig for at undgå at lyde afbryder hinanden.
Singleton Pattern – Refactoring Guru
Forklaring af Singleton design pattern brugt til GameManager og RoundManager.
https://refactoring.guru/design-patterns/singleton
Meget pædagogisk kilde med klare illustrationer og C#-eksempler. Bedre til at forstå mønsteret end den officielle Microsoft-dokumentation.
C# Events og Actions
Microsoft dokumentation for Events og Actions brugt til løs kobling mellem scripts.
https://learn.microsoft.com/en-us/dotnet/csharp/programming-guide/events/
Solid officiel dokumentation. Godt udgangspunkt for at forstå event-drevet arkitektur i C#.
C# Enum
Microsoft dokumentation for enum brugt til zombie state machine (Chase/Attack/Dead).
https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum
Kortfattet og præcis. Dækker præcis det der er nødvendigt for at implementere en simpel state machine.
yield / Coroutines (C#)
Microsoft dokumentation for yield-keyword brugt i Unity Coroutines.
https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/statements/yield
God supplement til Unitys egen Coroutine-dokumentation. Forklarer sproget bag yield frem for Unity-specifik brug.
Intermediate Gameplay Scripting
Unity Learn tutorial-serie om Coroutines og Singleton i Unity-kontekst.
https://learn.unity.com/project/intermediate-gameplay-scripting
Praktisk supplement til den teoretiske dokumentation. Viser konkrete Unity-implementeringer af avancerede C#-mønstre.
FreeSound.org
Database med gratis lydeffekter under Creative Commons licens.
https://freesound.org

Unity Asset Store – PxlTiger

https://assetstore.unity.com
Officiel Unitys platform for assets. Gratis modeller af varierende kvalitet – PxlTiger-modellen var brugbar og velanimeret.

Flutter – Global Gaming Booking App

Navigator (Flutter)
API-dokumentation for Navigator widget brugt til navigation mellem appens skærme.

https://firebase.flutter.dev/docs/firestore/usage

https://firebase.flutter.dev/docs/auth/usage

https://firebase.flutter.dev/docs/overview

Dart Language Tour
Officiel gennemgang af Dart-sprogets syntaks og funktioner.
https://dart.dev/guides/language/language-tour
Solid reference for Dart som sprog. Særligt nyttig i starten af projektet til at forstå null safety, typer og async/await i Dart-kontekst.
Stack Overflow
Brugt løbende til fejlsøgning, særligt til stale context-problemet og AndroidManifest-konfiguration.
https://stackoverflow.com
Uundværlig til konkrete fejl der ikke er dækket i officiel dokumentation. Kvaliteten af svar varierer, men de bedst upvotede svar er generelt pålidelige.
