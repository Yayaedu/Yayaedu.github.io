Noter

C# Grundlaeggende

  • Klasser er skabeloner – objekter er instanser af klasser
  • MonoBehaviour er base-klassen for alle Unity scripts
  • SerializeField eksponerer private variable i Inspector
  • Awake() koerer foer Start() – brug Awake til initialisering
  • Update() koerer hver frame, FixedUpdate() koerer fast (fysik)
  • Coroutines bruger yield return – tillader tidsforsinkede handlinger
  • Events og Actions bruges til loes kobling mellem scripts
  • Singleton pattern: een instans tilgaengelig globalt via static reference
  • async/await bruges til asynkrone operationer (Firebase, netvaerk)
  • enum definerer en naevnt maengde af konstanter

Unity Koncepter

  • GameObject er alle objekter i en Unity scene
  • Komponenter tilfojes GameObjects og definerer adfaerd
  • Prefabs er genanvendelige GameObject-skabeloner
  • NavMesh bages paa terran – NavMeshAgent navigerer automatisk
  • Raycast sender en usynlig strale og returnerer hvad den rammer
  • CharacterController giver FPS-bevaegelse uden Rigidbody-fysik
  • Canvas bruges til UI – World Space vs Screen Space
  • TextMeshPro giver bedre tekstrendering end standard UI Text
  • AudioSource afspiller lyd – AudioClip er selve lydfilen
  • URP (Universal Render Pipeline) – opgraderede shaders kraeves
  • ProBuilder bruges til at modellere 3D geometry direkte i Unity
  • Mathf.Pow(base, exponent) – bruges til eksponentiel svaerhedsgrad

Flutter og Dart

  • Alt i Flutter er widgets – UI bygges som et widget-trae
  • StatelessWidget har inget state – StatefulWidget kan opdateres
  • setState() fortaeller Flutter at UI skal genopbygges
  • BuildContext er en widgets "adresse" i widget-traeet
  • Navigator.push/pop bruges til navigation mellem skaerme
  • Future er et enkelt asynkront resultat – Stream er en kontinuerlig stroem
  • StreamBuilder genopbygger UI automatisk ved nye stream-data
  • GlobalKey bruges til at tilgaa FormState udefra
  • mounted-check er obligatorisk efter await i StatefulWidget
  • Navigator.pop() skal kaldes synkront foer enhver await-operation

Firebase

  • Firestore struktur: collections > documents > fields
  • Datoer gemmes som Timestamp – skal konverteres ved laesning
  • Offline persistence: data caches lokalt – kan skjule fejl
  • PERMISSION_DENIED vises ikke direkte hvis offline cache er aktiv
  • authStateChanges() er en stream der lytter paa login-status
  • Sikkerhedsregler defineres i Firestore Console – always validate
  • google-services.json skal vaere i android/app mappen
